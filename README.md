# TripFlow 出差申请

SvelteKit 差旅申请演示：申请人填报，主管 / 财务审批。无后端，数据存在浏览器 `localStorage`。

在线演示：https://ht-dylan.github.io/code-test/

## 功能

- **发起申请**：填写申请人与行程，可保存草稿或预览后提交
- **草稿续编**：详情页「继续编辑」改原单，不会另建一条
- **预览跳转**：预览页可回到对应区块继续改
- **审批流**：草稿 → 待主管审批 → 待财务审批 → 已通过；支持驳回、申请人撤回
- **角色切换**：顶栏切换申请人 / 主管 / 财务，列表按当前角色过滤
- **工作台 / 报表**：待办与近期申请，ECharts 看状态分布和月度趋势
- **本地恢复**：数据损坏或保存失败时提示，可重试；右上角可重置演示数据

## 怎么演示

1. 打开「发起申请」，选申请人（如陈晓），填行程后点「预览申请」→「确认提交」。
2. 顶栏把角色切到 **王经理**，打开刚提交的单，点「通过申请」。
3. 再切到 **孙会计**，同样通过，状态变为已通过。
4. 也可先「保存草稿」，到详情点「继续编辑」，改完再预览提交。
5. 驳回需填写原因；待主管阶段申请人可撤回。
6. 也可不新建，直接用下面的演示单：陈晓有一条苏州草稿（`app-007`），林悦有一条待主管的成都申请（`app-005`）。

首次打开或重置后，会写入这些 mock 账号和申请。右上角菜单可随时恢复。

## 实现说明

这是单页演示，所以用顶栏角色切换代替登录，用 `localStorage` 代替后端。业务规则（校验、状态流转、统计）在纯 TypeScript 模块里，页面只负责编排和展示。

## 技术栈

SvelteKit 2 + Svelte 5、TypeScript、Tailwind CSS 4、Vitest、Apache ECharts。静态导出，GitHub Pages 部署。

## 本地运行

需要 Node 22+ 和 [pnpm](https://pnpm.io/) 9。

```bash
pnpm install
pnpm run dev
```

打开 http://localhost:5173/

```bash
pnpm test          # 校验、审批流和主路径
pnpm run check     # 类型检查
pnpm run build     # 生产构建
```
